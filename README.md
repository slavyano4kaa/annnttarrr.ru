# annnttarrr.ru — Personal Bio Link Site

A fully custom, interactive, and modern "link-in-bio" website (similar to Linktree) with a built-in custom audio player and visual animations.

## Features

- **Interactive Preloader:** An entry screen transition with a "continue" button to initialize audio playback and smoothly reveal the main content.
- **Custom Audio Player:**
  - A global mini-player showing the current track title, artist, and progress bar.
  - An interactive playlist of tracks with individual play/pause buttons, seekable progress bars, and duration displays.
- **Modern Responsive Design:** Card layout styled with custom CSS, containing an animated avatar, customized typography (Raleway font), social media links (TikTok, Telegram, Steam), and interactive hobby/gaming badges.
- **Background Effects:** Seamless integration of wallpapers, gif animations, and smooth hover state transitions.

## Project Background & Status

This website was originally designed and built as a personal gift for my ex-girlfriend. However, the project is no longer maintained or updated due to our breakup caused by her betrayal. It is now published in this repository solely as a portfolio mini-project to demonstrate my skills in frontend development, responsive layout design, and custom audio player integration.

## Tech Stack

- **Frontend:** HTML5, CSS3 (Vanilla), JavaScript (Vanilla)
- **APIs:** HTML5 Audio API for custom playlist control and sync.

# annnttarrr.ru — Персональный сайт-визитка

Полностью кастомный интерактивный сайт-визитка (аналог Linktree) со встроенным музыкальным плеером и визуальными анимациями.

## Особенности

- **Интерактивный прелоадер:** Стартовый экран с кнопкой «continue» для инициализации аудио и плавного перехода к основному контенту.
- **Кастомный аудиоплеер:**
  - Глобальный mini-плеер с отображением названия трека, исполнителя и прогресс-бара.
  - Интерактивный плейлист треков с индивидуальными кнопками воспроизведения/паузы, перематываемым прогресс-баром и отображением длительности.
- **Современный адаптивный дизайн:** Карточка на чистом CSS, содержащая анимированную аватарку, кастомную типографику (шрифт Raleway), ссылки на соцсети (TikTok, Telegram, Steam) и интерактивные блоки с играми и хобби.
- **Фоновые эффекты:** Интеграция обоев, gif-анимаций и плавных переходов при наведении.

## Контекст проекта и статус

Этот сайт изначально разрабатывался как личный подарок для моей бывшей девушки. На данный момент проект больше не поддерживается и не обновляется в связи с нашим расставанием из-за измены с её стороны. Сайт опубликован в этом репозитории исключительно в качестве примера работы для портфолио, чтобы продемонстрировать навыки верстки, адаптивного дизайна и интеграции кастомного аудиоплеера.

## Стек технологий

- **Фронтенд:** HTML5, CSS3 (Vanilla), JavaScript (Vanilla)
- **API:** HTML5 Audio API для кастомного управления плейлистом и синхронизации.
